# craftflowlab.com — static source

This directory contains the static website currently served at `https://craftflowlab.com`.

- HTML pages: home, fit check, notes, systems, workflow teardown, and two project pages.
- `assets/`: project interface previews, concept screenshots, and site images.
- `favicon.svg`: the craftflowlab browser tab icon.

The production site is hosted on Vercel. This directory is the source copy used to preserve and restore its current pages and assets. The contact form posts to FormSubmit and shows its delivery status on the page.
